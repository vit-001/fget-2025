# fget3 (2025 version)

Десктопный медиаплеер на **PyQt6** для прямого воспроизведения видеопотоков без рекламы и лишних элементов веб-страниц.

## Основные возможности
* **Прямое воспроизведение:** получение и проигрывание видеопотоков напрямую без браузерных плееров и рекламных вставок.
* **Современный GUI на PyQt6 (`view_qt6`):** основной и активно развиваемый интерфейс приложения.
* **Модульная архитектура (MVC):** разделение бизнес-логики (`model`, `controller`), работы с форматами данных (`data_format`) и слоя отображения.

## Структура проекта
* `fget3.py` — точка входа в приложение
* `view_qt6/` — основной графический интерфейс на **PyQt6** (актуальная ветка развития)
* `model/` — логика работы с медиапотоками и источниками
* `controller/` — связующий слой управления
* `data_format/` — парсинг и обработка форматов данных и ссылок
* `interface/`, `common/`, `xutil/` — общие интерфейсы и вспомогательные утилиты
* `test/` — модульные тесты
* `view_qt5/`, `view_web/` — *устаревшие (legacy) реализации интерфейса, больше не поддерживаются*

## Быстрый старт

### Требования
* Python 3.10+
* **PyQt6**
* Установленный медиаплеер **VLC** (если используется бэкенд `python-vlc`)

### Установка и запуск
```bash
git clone https://github.com
cd fget-2025
pip install PyQt6
python fget3.py
```
