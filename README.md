# fget3 (2025 version)

Десктопный медиаплеер на **PyQt6** для прямого воспроизведения видеопотоков без рекламы и лишних элементов веб-страниц.

## Основные возможности
* **Прямое воспроизведение:** извлечение и проигрывание видеопотоков напрямую без браузерных плееров и рекламных вставок.
* **Обход ограничений при получении ссылок:** поддержка `yt-dlp` и имитации TLS-отпечатков браузера через `curl_cffi`.
* **Работа с буфером обмена:** быстрый подхват ссылок через `pyperclip`.
* **Современный GUI на PyQt6 (`view_qt6`):** основной и единственный поддерживаемый интерфейс приложения.
* **Модульная архитектура (MVC):** разделение бизнес-логики (`model`, `controller`), обработки форматов данных (`data_format`) и слоя отображения.

## Структура проекта
* `fget3.py` — точка входа в приложение
* `view_qt6/` — графический интерфейс на **PyQt6**
* `model/` — логика работы с медиапотоками, парсингом и источниками
* `controller/` — связующий слой управления
* `data_format/` — обработка форматов данных и ссылок
* `interface/`, `common/`, `xutil/` — общие интерфейсы и вспомогательные утилиты
* `test/` — модульные тесты

*(Предыдущие реализации интерфейса `view_qt5` и `view_web` удалены из актуальной ветки и доступны в теге `v1.0-legacy-qt5-web`.)*

## Требования
* **Python 3.10+**
* Установленный в системе медиаплеер **VLC** (необходим для работы `python-vlc`, если используется VLC-бэкенд)
* **Python-библиотеки** (указаны в `requirements.txt`):
  * `PyQt6` — графический интерфейс и мультимедиа
  * `python-vlc` — интеграция с движком VLC
  * `yt-dlp` — извлечение видеопотоков
  * `curl_cffi`, `requests`, `beautifulsoup4` — загрузка и разбор веб-страниц
  * `pyperclip` — работа с буфером обмена

## Установка и запуск

```bash
git clone https://github.com
cd fget-2025
pip install -r requirements.txt
python fget3.py
```
